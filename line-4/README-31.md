# Pepe 31 — The Changed Pebble

Added [Catalog Delta](tools/catalog-delta/README.md), an offline review tool for
comparing roots, releases, labels and dependency constraints across two finite
catalogs. Its demo compares two committed real Requests metadata projections:
three releases were added and root constraints changed, while shared-release
dependency maps did not. Six focused tests passed.

remain untouched. No letters, numbers or prohibited symbols were observed. The
mark is small; visual review is local and not independent certification.
